Archive Browsing Architecture

Navigation Flow

1. Open archive
   -> repo.open(path) -> handle
   -> repo.get_properties(handle) -> props
   -> repo.list_directory(handle, "") -> root entries
   -> VM caches under key ""

2. Navigate into "dir/"
   -> VM checks cache for key "dir/"
      MISS -> repo.list_directory(handle, "dir/") -> entries
      HIT  -> use cached entries
   -> VM.current_path = "dir/"
   -> VM.level_entries = sort(filter(entries))
   -> DataTable renders only visible rows (virtual scroll)
   -> Sidebar shows subdirectory list

3. Navigate up
   -> VM.current_path = parent path
   -> VM.level_entries = cached parent entries
   -> No additional repo call needed

4. Navigate into another dir
   -> Repeat step 2

5. Archive closed
   -> Clear directory_cache
   -> Close handle
